BOVA'S BOT — MASTER SUMMARY
Last update: 2026-09-10

PURPOSE
-------
Private Discord bot for Bovary Club Society only.
No public invites or panel links in the bot bio.
Developer credit: Bassani.

================================================================================
ARCHITECTURE
================================================================================
bot.py              Core, config, status rotation, avatar/banner apply
keep_alive.py       Flask / and /health
cogs/
  events.py         Auto-reactions ONLY (no channel/member log spam)
  weblogs.py        ONLY structured logs (toggles) — single source
  moderation.py     /delete /purge → logs via WebLogs
  utilities.py      /ping /info /timestamp /help /panel
  invite.py         Invite request panel
  autorole.py       Multi-role button panel
  meets.py          Meet announce + robust reminder + timezone_offset
  stats.py          Activity + media scores + matplotlib charts
  tickets.py        Tickets + auto transcript in data/transcripts/
  autofeeds.py      Interval OR fixed daily + optional embed
  boost.py          Boost thank-you → BOOST_CHANNEL_ID
  namehistory.py    Join registry + rename history → bot-room
utils/
  storage.py        Atomic JSON + .bak
  helpers.py        Embeds, media detect, TIMEZONES, SERVER_TZ
  cooldown.py       Persistent invite cooldown
web/                Static panel (sidebar layout)
data/               Runtime JSON + transcripts/

DEPLOY CHECKLIST
================================================================================
1. pip install -r requirements.txt  (discord.py, dotenv, Flask, matplotlib, aiohttp)
2. .env from .env.example — TOKEN, GUILD_ID, channel IDs
3. python bot.py  (or Render deploy)
4. Upload web/ to GitHub Pages repo; set PANEL_URL
5. Developer Portal: intents Message Content + Server Members; set bio text
6. Keep data/ across restarts

================================================================================
SAFE CHANGE GUIDE (for future edits)
================================================================================
- New feature → new cog under cogs/ + load_extension auto-picks *.py
- New log type → weblogs.py only (never duplicate in events.py)
- New channel ID → .env + bot._load_config + DEPLOY/sumario
- Panel dropdown data → web/js/config.js
- Panel access key → web/js/app.js ACCESS_KEY + PANEL_ACCESS_KEY in .env
- Storage always via utils.storage.save_json / load_json
- Never commit real TOKEN

================================================================================
KNOWN LIMITS
================================================================================
- Attachment URLs in delete logs may expire after Discord CDN purge
- Meet reminder needs bot online within ~35 min before start (catch-up window)
- Stats media history is not retroactive (only from deploy onward)
- Bot profile edit may fail if Discord rate-limits avatar changes
- Static panel cannot sync live Discord data without a backend API
