================================================================================
API
================================================================================
Base URL = your Render service URL (same as the bot)

Headers on every protected route:
  X-API-Key: <PANEL_ACCESS_KEY>
  X-Discord-User-Id: <your discord snowflake>

Routes:
  GET  /health
  POST /api/embed
  POST /api/meet
  GET  /api/stats/summary
  GET  /api/namehistory

Panel: set window.BOVA_API.baseUrl in web/js/config.js
First API action prompts for Discord User ID (stored in localStorage).

  FORCE_COMMAND_RESYNC=true — use once to clear ghost /autofeed_*, then remove.

2026-09-28 HOTFIX v2.9.6 — BREAK THE 429 COMMAND-SYNC LOOP
================================================================================
- Discord kept returning 429 every ~7 minutes on guild command PUT; continuous
  retries never completed so the slash list stayed empty after the earlier wipe.
