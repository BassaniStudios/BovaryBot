BOVA'S BOT — v2.2-api  (2026-09-10)
================================================================================

VERSION FOLDER NAME: BovaryBot-v2.2-api

WHAT'S NEW IN 2.2
-----------------
- HTTP API on the same Render process (api.py + Flask + flask-cors)
- Web panel can POST embed / meet / autorole panel / autofeed
- Auth: X-API-Key + X-Discord-User-Id with role STAFF_API_ROLE_ID
  default role: 1547647694997037137 (or administrator)
- APPLY_BOT_PROFILE=false by default → banner/avatar no longer overwritten
- Private bot guidance (Public Bot OFF in Developer Portal)

================================================================================
API
================================================================================
Base URL = your Render service URL (same as the bot)

Headers on every protected route:
  X-API-Key: <PANEL_ACCESS_KEY>
  X-Discord-User-Id: <your discord snowflake>

Routes:
  GET  /health
  POST /api/embed
  POST /api/meet
  POST /api/autorole/panel
  POST /api/autofeed
  GET  /api/autofeeds
  GET  /api/stats/summary
  GET  /api/namehistory

Panel: set window.BOVA_API.baseUrl in web/js/config.js
First API action prompts for Discord User ID (stored in localStorage).

================================================================================
RENDER ENV (minimum)
================================================================================
TOKEN=
GUILD_ID=
PANEL_URL=https://bovaryclub.github.io/BovaryBot-Panel/
PANEL_ACCESS_KEY=BOVA-CORE-2026
STAFF_API_ROLE_ID=1547647694997037137
CORS_ORIGIN=https://bovaryclub.github.io
APPLY_BOT_PROFILE=false
PUBLIC_API_URL=https://YOUR-SERVICE.onrender.com

Start command: python bot.py
Build: pip install -r requirements.txt
Must be Web Service (open PORT) so API is reachable.

================================================================================
PANEL REPO
================================================================================
Upload web/ contents only.
Edit js/config.js → BOVA_API.baseUrl = Render URL (no trailing slash).

================================================================================
PRIVATE BOT
================================================================================
Developer Portal → disable Public Bot / public install.
Code never generates invite links for the bot itself.

================================================================================
BANNER FIX
================================================================================

Edit banner only in Developer Portal.
